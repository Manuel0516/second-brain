READY FOR LOCAL TESTING
================================================================================

To start testing:

  1. npm install
  2. uv sync --project apps/api --dev
  3. docker compose -f compose.yaml -f compose.dev.yaml up -d db minio
  4. Generate JWT secret: python3 -c "import secrets; print(secrets.token_urlsafe(32))"
  5. Add to .env: JWT_SECRET_KEY=<your-secret>
  6. cd apps/api && alembic upgrade head && cd ..
  7. npm run dev:api  (Terminal 1)
  8. npm run dev:web  (Terminal 2)
  9. Go to http://localhost:5173

Follow LOCAL_TESTING_GUIDE.md for 8 complete test scenarios.
